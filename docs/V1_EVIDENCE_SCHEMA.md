# V1 evidence schema

Each acquisition root has provenance, supervised worker lifecycle records and a complete marker only after every prescribed trial finishes. Parent launch/closure/resource records retain the single deadline, boot-scoped clock, source revision, requested worker count and actual monitor samples. The nominal1s monitor incurs filesystem/process-query overhead; use actual timestamps when reporting cadence.

Each `nN_rR` folder contains exact initial neural/checkpoint/OU hashes in `trial.json`, prefix observations/receipts, fit record and information/history arrays. Seed roles are the original `Config`/SeedSequence roles, not new random network draws. A branch file is complete only with a corresponding trial branch record after the fixed horizon. Segment files alone are never successful branches.

`counts`: bins×20 integer spikes. `time_us`: start,stop,available integer microseconds. `valid`/`coverage_us`: bin×20 permitted channel masks/coverage. `event_offset`, `event_time_us`, `event_channel`: ragged observed spike events. `rates`: archived causal filtered rates; `sector`: archived sector rates. Primary scores are reconstructed from raw E counts, not these filtered fields. Each sector has four E recording channels and one I channel; 20 E cells/sector,80 total. `requested`/`delivered`: bins×4 pA, causal validated commands and actual receipts. Commands have already undergone controller projection, so these vectors agree when delivered successfully; original planner desired doses are in plans/policy state.

`frames` for predictive controllers: time_us,q,safe,recover,received,updates,skips,failure_flag. Reference frames: time_us,q,integral,last_error,antiwindup_blocked,clipped,safe,updates. Their column meanings differ intentionally and are never mixed. `presented` records online availability; raw neural masks remain genuine recording validity. For declared DELAY faults, stale observations are discarded; they are not silently reassimilated.

`pre_prediction`: four-sector forecast before the associated observed outcome/update. `dense_theta`, `dense_p`, `dense_bias`: exact model values after each1s of completed data. `state_hashes`: SHA256 of theta/P/bias float64 bytes after every20ms update. Initial record plus inputs/outcomes reconstructs these values; hashes verify the lossless codec. `command_ns`/`update_ns`: measured suspend-inclusive wall time; no hard real-time claim. StepResult's optimized internal neural-time placeholder is zero and is not used as a measured per-bin neural benchmark.

Plan files retain origin_us, all625 candidate tracking/dose/switch/total costs and exposure, selected index/q0/q1, minimum forecast, measured elapsed_ns, frozen origin coefficients/history and selected100bin forecast. The planner anticipates its own feasible future commands; only the first second is executed, subject to per20ms safety. Evaluator gain changes are absent from controller inputs and identified only by the frozen condition/time archive.

Main analysis emits repeat-level metrics, raw1s time courses, per-network qualification and whole-network bootstrap summary. Independent verification uses raw files and a separately implemented target/statistical calculation. Source/data manifests and complete trial markers, rather than directory names alone, establish lineage.
