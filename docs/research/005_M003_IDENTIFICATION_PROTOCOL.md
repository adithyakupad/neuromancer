## Question, hypotheses and decisions

Can delivered-stimulation-aware linear predictors forecast intervention-induced changes in four observed unstimulated E sector rates, beyond matched stimulation-blind autoregression and a time-shuffled-input control?

Primary H1: ARX reduces reserved **1s mean evoked-response MSE** versus AR by>=10%, with mean absolute MSE reduction>=.04Hz² and the paired network-bootstrap95% lower bound on absolute improvement>0. The.04Hz² floor is an engineering effect-size requirement (squared.2Hz), not a biological measurement or a claim of.2Hz RMSE improvement. Also require the same relative/absolute/interval thresholds against shuffled-input ARX, and positive absolute benefit against both comparators in>=8/10 development networks. These are conjunctive gates, not a choice of whichever baseline loses. No bin-level hypothesis test. Failure is scientific FAIL/HOLD or inconclusive precision, not automatically software failure.

Constant and AR receive the same common-origin observation history as ARX, but ignore the planned action. Their open-loop intervention-minus-sham forecast is consequently exactly zero. H1 alone therefore cannot establish mechanistic identification or the necessity of autoregressive dynamics. The shuffled-input guard challenges spurious action association. Ordinary rate prediction is a separate endpoint and cannot substitute for the causal-response endpoint. Even a positive result only identifies useful input-response prediction in this simulator family.

Execution PASS requires complete fixed development/null cohort, valid timing/replay/constraints/data access, stable numerical implementation, regression/new tests, independent recomputation and complete artifacts. Finite scientific failure still permits execution PASS. Numerical/lineage/causal-order faults yield execution FAIL/PARTIAL, not a favorable scientific result. No cohort exclusion/replacement or threshold revision.

## Statistical analysis and gates

Network is principal independent unit. Development10 networks x3 noise repeats; validation5x3,stress10x1. Never pool bins/outputs/pulses as independent units. Bootstrap whole network vectors10,000 draws seed20261030, percentile95% intervals, preserving paired methods/conditions. Compute relative improvement per network=(MSE_comparator−MSE_ARX)/max(MSE_comparator,.04Hz²); report floor incidents, raw absolute reductions and all network/noise values. Primary H1 needs mean relative>=.10, mean absolute>=.04Hz², absolute-improvement CI lower>0; all identical guards versus shuffled ARX. Positive benefit in>=8/10 development networks for both comparisons (validation4/5). These conjunctive confirmatory guards do not license choosing a secondary horizon or subgroup. Intervals for other metrics are descriptive. No claim from a favorable relative denominator alone, no significance from bins.

Scientific D failure ->stop V/G; report FAIL if effect magnitudes fail, or HOLD/inconclusive if point effects pass but interval guard fails. Execution can PASS with scientific failure.
