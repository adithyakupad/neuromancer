# Prospective Intel fingerprint decision

Status **proposed only**. The M029 strict worker-count fingerprint remains the release gate. The diagnostic evidence has no promotion authority.

The archived model-state digest and the Intel worker-count fingerprint serve different purposes. An archived digest authenticates a particular binary64 state on its reference path. The worker-count fingerprint additionally demands byte equality of the new native trajectories and numerical proof records across schedules. The approved operation-derived contract can compare different floating states and preserve exact discrete decisions. It does not itself remove the worker-count equality requirement.

| Option | Required evidence |
| --- | --- |
| Retain strict worker-count equality | Find a reproducible execution arrangement whose untouched native trajectory hashes and proof fingerprints agree. Use the same original states, inputs, chronological checks, actions and time budget. |
| Prospectively approve proof equivalence for this gate | Verify exact branch identities, state initialization, inputs, candidate banks, discrete events and policies. Certify each native and archived state under continuous common information equations, positive denominators and original outward bounds. Preserve both raw fingerprints and all deviations as evidence. Require the original tie and ambiguity checks on every plan. |

The second option changes only the scheduling equivalence acceptance rule. Each certificate would continue to use the same mathematical bounds, intermediate checks and original 240-second full-stage limit. Native implementations, archived bytes, historical failures and scientific outcomes retain their existing provenance. A bound crossing an original algorithm or decision guard fails qualification.

Neither option is qualified by a partial Intel component run. A change to the gate needs an explicit prospective decision followed by a complete 40-branch run on each platform, the full remaining numerical audit and exact-source release checks. Publication remains HOLD.
