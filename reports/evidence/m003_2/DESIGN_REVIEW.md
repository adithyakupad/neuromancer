# Pre-scoring scientific audit

Written before reserved-outcome scoring; does not change the preregistration.

- The comparison tests observable *effect modification*, not merely prediction of future baseline activity. Primary labels are within-origin active-minus-sham; high-minus-low absolute rates alone are insufficient. Explicit origin×input terms can express state dependence whereas additive ARX contrasts cancel history.
- Both origins have zero stimulation throughout their selection trajectory, and each receives identical action schedules/exposure. State is not randomized; elapsed time and latent conditions associated with a recorded-rate stratum remain potential correlates. Conditional response prediction would not establish that changing the measured scalar itself causes an effect change.
- Training is deliberately supervised using completed paired simulator counterfactuals. This enables a clean model-necessity audit but is not a demonstrated online biological calibration method. All primary families receive the same paired labels, plans, sample windows and penalty grid. Reserved sham labels remain unavailable to forecasts.
- There are only four FIT origins (two independent noise streams), two validation origins and four reserved origins per network. Repeated actions from a restored origin share future noise.24 active training episodes are not24 independent neural states; half-data has12episodes/two origins/one noise stream. Ten independent networks remain the inference unit. Sector-specific interactions were deferred for this reason.
- The state feature is only a global recorded-rate scalar averaged over100ms. It cannot identify all relevant latent state, synchrony, voltages, sector-specific effects or longer histories. Failure of this feature/model/horizon cannot establish state independence in general.
- The shuffled-state control swaps LOW/HIGH labels within fitreplicate. It preserves marginal values and can invert, rather than annihilate, information. Its failure/success needs cautious interpretation; the primary unshuffled-versus-FIR threshold remains necessary. Input shuffling is deliberately misaligned training, not a plausible deployment model.
- FIR support is fixed200ms from the previously selected family; no outcome-driven lag extension. One-second averaging can suppress transient interaction. Secondary20ms/200ms/2s results cannot rescue the frozen primary gate. Different pulse durations/amplitudes are a finite bank, not all neural regimes.
- Empirical intervals use the same one-noise validation phase as penalty selection, with dependent actions/sectors. Coverage is descriptive, not certified. Bootstrap draws preserve whole-network pairing; neither bins nor restored pulses are independent neural populations.
- At zero effective coupling all actual branch observations must equal sham. A model trained atg1 and uninformed ofg0 can still forecast nonzero responses; record that limitation rather than call its false response correct. No true gain reaches selection or prediction.
- No change to substrate, protocols, current bounds, integration, membership, model selection or thresholds is permitted after outcomes. A negative result supports retaining FIR within this tested regime, not another target-engineering rescue or a controller claim.
