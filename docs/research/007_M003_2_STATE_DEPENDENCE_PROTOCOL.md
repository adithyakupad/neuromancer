## Hypothesis and decisions

Primary H1: a scalar recorded-origin-rate × input FIR interaction reduces reserved 1-second mean stimulation-minus-sham prediction MSE versus input-only FIR by mean relative >=10%, mean absolute >=0.04 Hz², paired whole-network percentile 95% CI lower absolute bound >0, and positive improvement in >=8/10 networks. Additionally its paired improvement over shuffled-state interaction must have a positive network CI lower bound. These new engineering thresholds carry forward the *magnitude* standards of M003.1 for comparability, not its acceptance interpretation: .04 Hz² is a squared .2 Hz practical error scale and 10% guards complexity for negligible benefit. Relative improvement per network divides by max(FIR MSE,.04); report floors. All conditions required; magnitudes/count passing but CI failing => HOLD, otherwise FAIL. Failure retains FIR as default, not evidence of biological state independence.

Claim 1 (observations predict activity), claim 2 (observations modify predicted stimulation effect), claim 3 (state improves decisions) are distinct. Only claim 2 is primary. ARX absolute-rate forecasting is secondary; no decision/controller claim is tested. Explicit bilinear interaction avoids the additive ARX contrast cancellation demonstrated in M003.1.

## Transparent models and fitting

We fit **direct intervention-effect predictors using completed paired simulator training data**. This deliberately uses simulator-only counterfactual training labels, identically for FIR/STATE/controls; it is not an online biological identification procedure. No reserved sham outcome or future observation is supplied before forecasting. Forecast artifacts must be finalized/hash-recorded before confirmation evaluator opens reserved rates. Predictor accepts known input plan, optional causal scalar origin feature and fitted coefficients, never sham outcomes/private state. Shared initial input history iszero; shared absolute baseline estimate for FIR/STATE is the completed four-sector origin rate (last completed bin), added to effect forecasts only for descriptive absolute-rate errors.

For each training active branch and bin k, Xk=[u[k],u[k−1],...,u[k−9]], zeros before origin (frozen selected-family FIR q=10;40features,200ms support). Target dk=y_active[k]−y_S[k], four original filtered rates. No intercept: exact zero input implies zero predicted effect. FIR: d_hat=X B (160coefficients). STATE: d_hat=[X,z X]B (320coefficients), z=(a_origin−fit_mean_a)/max(fit_SD_a,.1Hz). Scalar calibration fixed over each2s forecast, no future neural observations. Fit mean/SD across training origins equally. Feature scales fit-only RMS with floor1 in pA units; no feature centering (preserve zero response). Ridge minimize mean squared error+lambda||beta||² via augmented least squares. Lambda grid {.0001,.001,.01,.1}, same four candidates each. Select a single global lambda per family by validation28 mean1s effect MSE, equal network/stratum/action weights; ties1e−12 choose largerlambda. Per-network coefficients fitted on26,27 only; selection never sees29,30.

STATE_SHUFFLED: within each fit replicate swap LOW/HIGH scalar labels, leaving inputs/effect targets unchanged; fixed deterministic stratum permutation. This preserves state distribution/calibration while breaking correspondence, but a two-stratum swap is not guaranteed to eliminate all information and can invert a true relationship. Therefore also report actual predictions/coefficients and interpret control cautiously. FIR_SHUFFLED: cyclically roll training input-lag feature rows by25bins within each action episode, leave targets unchanged, fit and select ownlambda. Correct planned inputs used at prediction. No null-specific retraining. Rank, raw standardized singular values/condition, penalized condition, coefficient count/norm all saved. Rank deficiency is reported, not automatic rejection because ridge explicitly regularizes collinear interaction features; reject nonfinite solution or augmented condition>1e8, forecasts abs>100Hz. No clipping/fallback.

ARX secondary: original p4,q4 additive model, 32features+intercept,132coefficients. Pool completed absolute active and sham FIT branches, causal lag histories from last50 origin observations and zero inputs; fit-only feature mean/SD floor1 and output centering, same ridgegrid. Select by validation1s absolute forecast MSE, common origin, recursive forecast. Its intervention contrast is input-only by algebra; never primary comparator.
